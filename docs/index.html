Windows 10/11 · 64-bit · ~95 MB · Versie 1.0.0

Alles wat je nodig hebt

Gebouwd voor mensen met duizenden foto's verspreid over meerdere locaties.

🔍

Duplicaatdetectie

Vindt exact dubbele foto's op basis van MD5-hash, ook als de bestandsnaam verschilt.

🗺️

GPS-kaart

Bekijk welke foto's waar zijn genomen op een interactieve kaart. Handmatig GPS toewijzen ook mogelijk.

📊

Dashboard & statistieken

Statistieken per jaar, camera, land — voor zowel foto's als video's afzonderlijk.

📷

RAW-ondersteuning

Thumbnails van RAW-bestanden via exiftool (Canon CR2/CR3, Nikon NEF, Sony ARW, enz.).

📤

Slimme export

Exporteer met automatische bestandsnamen: Nederland_Amsterdam_15_06_2023.jpg geordend per jaar/maand.

🏳️

Google Takeout

Importeer je Google Foto's export inclusief datum en GPS-data uit de JSON-bestanden.

🌎

Automatische geocoding

GPS-coördinaten worden automatisch omgezet naar stad en land via Nominatim (geen API-sleutel nodig).

⚡

Snel & responsief

Duizenden foto's pagineren zonder vertraging. Thumbnails worden gecached in de database.

🎬

Video-ondersteuning

MP4, MOV, AVI en meer. Aparte statistieken en grafieken voor foto's en video's.

Waarom lokaal?

Jouw foto's zijn van jou — niet van een clouddienst.

🔒

Privé

Geen uploads. Geen servers. Alles blijft op jouw machine.

💰

Gratis voor altijd

Geen abonnement, geen "premium" versie. Volledig open source.

📶

Offline

Werkt volledig zonder internet (na installatie). Geen afhankelijkheid van externe servers.

🚀

Snel

SQLite lokale database. Geen netwerkvertraging. Directe resultaten.

Installeren in 3 stappen

Windows 10 of hoger vereist.

1

Download de installer

Klik op de downloadknop. Het bestand heet FotoApp-Setup-1.0.0.exe (~95 MB).

2

Installeer de app

Dubbelklik op het bestand. Bij een SmartScreen-waarschuwing: klik "Meer informatie" → "Toch uitvoeren".

3

Open FotoApp & voeg een map toe

Start via het startmenu. Ga naar Bronnen → kies een map met foto's → klik Scannen.

Free local photo management software

FotoApp is a free, open-source desktop application for organizing photos and videos without cloud dependency.

Features include duplicate detection, GPS map, EXIF viewer, RAW support, Google Takeout import, and smart export with automatic file naming.

Available for Windows. Source code available on GitHub for Mac and Linux builds.
