# Bijdragen aan FotoApp

Bedankt dat je wil bijdragen! FotoApp is een community-project en elke bijdrage telt — of het nu code is, een bugmelding, een vertaling of een idee.

---

## 🐛 Een bug melden

1. Ga naar [GitHub Issues](https://github.com/boulbaal/fotoApp/issues)
2. Klik op **New Issue**
3. Beschrijf:
   - Wat je deed
   - Wat je verwachtte
   - Wat er werkelijk gebeurde
   - Je besturingssysteem (Windows / Mac / Linux)
4. Voeg screenshots toe als dat helpt

---

## 💡 Een feature voorstellen

Open een Issue met het label **enhancement** en beschrijf:
- Welk probleem het oplost
- Hoe je het je voorstelt
- Waarom het nuttig is voor andere gebruikers

---

## 🔧 Code bijdragen (Pull Request)

### 1. Fork en clone
```bash
git clone https://github.com/JOUW-GEBRUIKERSNAAM/fotoApp.git
cd fotoApp
npm install
```

### 2. Maak een branch
```bash
git checkout -b mijn-feature-beschrijving
```

### 3. Maak je wijzigingen
- Schrijf duidelijke, leesbare code
- Voeg tests toe voor nieuwe functionaliteit
- Zorg dat alle bestaande tests slagen: `node tests/run-tests.js`

### 4. Commit
```bash
git add -A
git commit -m "feat: korte beschrijving van wat je deed"
```

Commit types: `feat:` `fix:` `refactor:` `test:` `docs:`

### 5. Stuur je Pull Request
- Beschrijf wat je gewijzigd hebt en waarom
- Link naar het Issue als er een bestaat
- Wacht op feedback — we reageren zo snel mogelijk

## 🌍 Vertalingen

De app is momenteel in het Nederlands. Wil je helpen met een Engelse, Franse of andere vertaling? Open een Issue met het label **translation** — we helpen je op weg.
